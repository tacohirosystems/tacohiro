# Discord setup requirements

### Installation

Create a Discord bot with the following:

#### Contexts

- Guild Install

#### Install Link

- Discord Provided Link

#### Guild Install Scopes

- application.commands
- bot

#### Guild Install Permissions

- Read Message History
- Send Messages
- Use External Emojis
- Use Slash Commands

### Environment variables

- `DISCORD_BOT_TOKEN`
- `DISCORD_CLIENT_ID`
- `DISCORD_CLIENT_SECRET`
- `DISCORD_APPLICATION_ID`
- `DISCORD_PUBLIC_KEY`
